# Quiz Major — instaladores

Este repositório guarda só os **instaladores** do Quiz Major: um app de bandeja
para Windows que treina o peg system do sistema Major (a lista de imagens
associadas aos números, 00–99) com quizzes-relâmpago ao longo do dia. O
código-fonte é privado.

## Instalar

1. Baixe o `.exe` mais recente em [Releases](../../releases/latest).
2. O Windows vai dizer que não reconhece o app — o instalador não tem
   certificado de assinatura. Clique em **Mais informações → Executar assim
   mesmo**.
3. A instalação é só para o seu usuário (não pede senha de administrador). O app
   abre na bandeja do sistema e passa a subir junto com o Windows.

## Atualizações

Depois de instalado, **o app se atualiza sozinho**: ele consulta este
repositório algumas vezes por dia e instala a versão nova quando você não está
com nenhuma janela aberta. Não precisa baixar nada de novo aqui.

Em **Configurações → Atualizações** também dá para verificar na hora.

## Primeiros passos

- **Pegs → Importar**: o app começa vazio; traga sua lista de uma planilha
  Excel ou CSV (colunas: número, objeto).
- **Configurações → Google Calendar → Conectar**: abre o navegador para você
  autorizar sua conta Google. Com a agenda conectada, nenhum quiz cai em cima de
  uma reunião.
